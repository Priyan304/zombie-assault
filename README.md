# Retro Zombie Assault

**HOLD THE LINE. OUTLIVE THE DEAD.**

Retro Zombie Assault is a fast-paced, top-down wave survival shooter built with HTML, CSS, and Vanilla JavaScript. Fight off hordes of zombies, survive through increasingly difficult sectors, and defeat the Mutant Overlord!

## 🛠️ Features
- **Wave-Based Survival**: Survive multiple waves and sectors with increasing difficulty.
- **Weapon System**: Start with a Pistol and unlock powerful weapons like the Shotgun.
- **Dynamic Combat**: Includes ammo management, realistic reload times, and projectile mechanics.
- **Boss Fights**: Face off against the fearsome Mutant Overlord with a dynamic health bar and enraged phases.
- **Responsive UI/HUD**: Real-time stats for health, ammo, score, and XP.

## ⌨️ Controls
- **WASD or Arrow Keys**: Move your character.
- **Spacebar or Mouse Click**: Fire your weapon.
- **R Key**: Reload your current weapon.

## 🚀 Setup & Installation
Since this is a client-side web application, no build tools are required to run it locally.
1. Clone the repository:
   ```bash
   git clone https://github.com/Priyan304/zombie-assault.git
   ```
2. Navigate to the project directory:
   ```bash
   cd zombie-assault
   ```
3. Open `index.html` in your favorite web browser.
   *(Alternatively, use a local server like Live Server in VS Code for the best experience).*

## 💻 Tech Stack
- **HTML5**: Game structure and HUD elements.
- **CSS3**: Styling, layout, and animations (including a retro grain effect).
- **JavaScript (Vanilla)**: Core game logic, physics, entity management, and game loop.
